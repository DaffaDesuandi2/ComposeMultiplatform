# My Profile App

Aplikasi Android sederhana untuk menampilkan profil pengguna.
Aplikasi ini dibuat menggunakan Kotlin dan Jetpack Compose sebagai latihan membuat UI dasar di Android.

## Fitur

* Menampilkan foto profil / icon profil
* Menampilkan nama dan bio
* Informasi kontak (email, nomor telepon, lokasi)
* Tombol Follow
* Menggunakan komponen UI seperti Column, Row, Card, Text, Icon, dan Button

## Teknologi yang Digunakan

* Kotlin
* Jetpack Compose
* Material 3
* Android Studio

## Struktur Komponen

Aplikasi ini menggunakan beberapa composable function agar kode lebih rapi dan bisa dipakai ulang:

* `ProfileHeader()` → menampilkan foto profil, nama, dan bio
* `ProfileCard()` → card yang berisi informasi profil
* `InfoItem()` → baris untuk menampilkan icon dan teks (email, phone, location)

## Cara Menjalankan Project

1. Clone repository ini
2. Buka project di Android Studio
3. Sync Gradle
4. Jalankan aplikasi di emulator atau device Android

## Tujuan Project

Project ini dibuat untuk latihan:

* membuat UI dengan Jetpack Compose
* menggunakan composable function
* memahami layout dasar di Android
